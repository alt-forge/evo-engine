# Evo Engine 🧬

**Evo Engine** — это исследовательский проект, нацеленный на изучение процессов эволюции. 

Основным объектом проекта является библиотека `evoengine` — это полноценная симуляция искусственной жизни, в которой нейросетевые агенты учатся выживать, искать еду и передавать свои навыки потомкам через мутации. Библиотека позволяет как наблюдать за эволюцией в реальном времени (через графический движок Pygame), так и использовать чистый движок для собственных экспериментов (headless).

![Демонстрация симуляции](https://alt-forge/evo-engine/images/gif.gif)

# 🧠 Как это работает
- Мир: Двумерная сетка с едой и стенами.
- Агенты: У каждого есть запас здоровья (HP), возраст и своя нейросеть.
- Восприятие (Vision): Агент "видит" пространство вокруг себя на заданное расстояние.
- Действия: Стоять, идти вправо/влево/вверх/вниз.
- Метаболизм: Каждый шаг и каждое движение тратят энергию (HP).
- Еда: Восстанавливает HP. Возобновляется периодически.
- Размножение: Если HP агента превышает порог, он создает потомка в свободной клетке рядом. Потомок получает сеть родителя с небольшими случайными мутациями.
- Смерть: Наступает при HP <= 0 или по достижении предельного возраста.

# 🚀 Быстрый старт
1) Склонируйте репозиторий:
    ```bash
    git clone https://github.com/ваш_ник/evo-engine.git
    cd evo-engine
    ```
2) Перейдите в папку с библиотекой и установите её:
    ```bash
    cd evoengine
    pip install -e .
    ```
3) Вернитесь в корень проекта и запустите симуляцию:
    ```bash
    cd ..
    python main.py
    ```

# 📦 Установка как независимой библиотеки
1) Скачайте папку evoengine из проекта
2) Перенесите в удобное место
3) Установите:
    ```bash
    pip install -e "путь/evoengine"
    ```
p.s: вы можете установить библиотеку как в venv, так и в path.

# 💡 Пример использования как библиотеки
    ```python
    from evoengine import SimConfig, RngBundle, World, Env, Agent

    # Создаем конфигурацию мира
    cfg = SimConfig(world_size=50, seed=42)
    rng = RngBundle(cfg.seed)

    # Создаем мир и среду
    world = World(cfg, rng)
    env = Env(cfg, rng, world)

    # Добавляем агента
    env.add_agent(Agent(cfg, rng, x=25, y=25))

    # Делаем шаг симуляции без графики (headless)
    env.step()
    print(f"Агентов после шага: {len(env.agents)}")
    ```

# 🛠️ Технологии
- Python 3.10+ — основной язык.
- NumPy — для матричных операций (нейросети).
- Pygame — для отрисовки графики и интерфейса.
- Setuptools — для сборки и установки пакета.
